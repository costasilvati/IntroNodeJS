_>9 Integra de APIs Node.js com Banco de Dados

Código desenvolvido em aula

Neste capítulo vamos integrar a API desenvolvida anteriormente com um banco de dados relacional. Utilizaremos o MySQL em conjunto com Node.js e Express para implementar operações de persistência de dados utilizando SQL.

Segundo Lecheta,27 uma API sem persistência normalmente perde os dados ao reiniciar o servidor. Por isso, aplicações reais utilizam bancos de dados para armazenar informações permanentemente.

Também utilizaremos como referência a documentação do Express sobre integração com banco de dados28 e os exemplos de MySQL para Node.js apresentados pelo W3Schools.29

Ao final deste capítulo, a API será capaz de:

  • listar carros;
  • buscar um carro específico;
  • inserir novos carros;
  • atualizar carros;
  • remover carros;
  • organizar o código utilizando classes.

9.1 Banco de dados da aplicação

A aplicação utilizará um banco chamado:

api_carros

A tabela principal será:

carros

9.2 Criando o banco de dados

Antes de desenvolver a API, precisamos criar o banco de dados.

Execute os comandos SQL abaixo no MySQL:

CREATE DATABASE api_carros;

Selecionando o banco:

USE api_carros;

Criando a tabela:

CREATE TABLE carros (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    marca VARCHAR(100) NOT NULL,
    ano INT NOT NULL,
    preco DECIMAL(10,2) NOT NULL,
    placa VARCHAR(7) NOT NULL
);

Inserindo alguns registros:

INSERT INTO carros (nome, marca, ano, preco, placa)
VALUES
('Fusca', 'Volkswagen', 1972, 25000, 'FUS1C80'),
('Ferrari F40', 'Ferrari', 1987, 1500000, 'FER4R11'),
('Porsche 911', 'Porsche', 2020, 950000, 'POR5H31');

9.3 Instalando o driver MySQL

Para conectar Node.js ao MySQL, utilizaremos a biblioteca mysql2.

Segundo a documentação do Express, aplicações Node.js normalmente utilizam bibliotecas específicas para comunicação com bancos relacionais.30

Instale a dependência:

npm install mysql2

O package.json será atualizado automaticamente:

"dependencies": {
  "express": "^5.0.0",
  "mysql2": "^3.0.0"
}

9.5 Conectando-se ao banco de dados

Crie o arquivo:

database/connection.js

Conteúdo:

const mysql = require('mysql2');

const connection = mysql.createConnection({
  host: 'localhost',
  user: 'root',
  password: '',
  database: 'api_carros'
});

connection.connect((erro) => {

  if (erro) {
    console.error('Erro ao conectar no banco:', erro);
    return;
  }

  console.log('Conectado ao MySQL');

});

module.exports = connection;

Neste exemplo:

  • mysql.createConnection() cria a conexão;
  • host indica o servidor;
  • user e password representam o usuário do banco;
  • database indica o banco utilizado.

Segundo o W3Schools, o objeto de conexão permite executar comandos SQL diretamente pelo Node.js.31

9.7 Web service que retorna lista de carros

Arquivo:

routes/carros.js
const express = require('express');

const router = express.Router();

const connection = require('../database/connection');

router.get('/', (req, res) => {

  const sql = 'SELECT * FROM carros';

  connection.query(sql, (erro, resultados) => {

    if (erro) {

      return res.status(500).json({
        erro: 'Erro ao buscar carros'
      });

    }

    res.json(resultados);

  });

});

module.exports = router;

Neste exemplo:

  • SELECT * FROM carros busca todos os registros;
  • connection.query() executa o SQL;
  • resultados contém os dados retornados.

9.8 Selecionando registros na tabela (SELECT)

O comando SQL:

SELECT * FROM carros;

retorna todos os registros.

No Node.js:

connection.query('SELECT * FROM carros', (erro, resultados) => {

  console.log(resultados);

});

9.9 Selecionando um registro específico

Podemos buscar um carro específico utilizando o ID.

9.9.1 Rota

/carros/:id

9.9.2 Código

router.get('/:id', (req, res) => {

  const id = req.params.id;

  const sql = 'SELECT * FROM carros WHERE id = ?';

  connection.query(sql, [id], (erro, resultados) => {

    if (erro) {

      return res.status(500).json({
        erro: 'Erro ao buscar carro'
      });

    }

    if (resultados.length === 0) {

      return res.status(404).json({
        erro: 'Carro não encontrado'
      });

    }

    res.json(resultados[0]);

  });

});

9.10 O que significa o caractere ?

O caractere ?.

é um placeholder utilizado para evitar SQL Injection.

O valor real é enviado separadamente: [id]

Segundo a documentação do MySQL2, esse mecanismo faz o escape automático dos valores.32

9.11 Inserindo registros na tabela (INSERT)

Agora vamos permitir inserção de carros.

9.11.1 Método HTTP

POST

9.11.2 Código

router.post('/', (req, res) => {

  const { nome, marca, ano, preco } = req.body;

  const sql = `
    INSERT INTO carros (nome, marca, ano, preco)
    VALUES (?, ?, ?, ?)
  `;

  connection.query(
    sql,
    [nome, marca, ano, preco],
    (erro, resultado) => {

      if (erro) {

        return res.status(500).json({
          erro: 'Erro ao inserir carro'
        });

      }

      res.status(201).json({
        mensagem: 'Carro inserido com sucesso',
        idInserido: resultado.insertId
      });

    }
  );

});

9.11.3 JSON enviado

{
  "nome": "BMW Série 7",

  "preco": 750000
}

9.12 Atualizando registros na tabela (UPDATE)

Método:

PUT

9.12.1 Código

router.put('/:id', (req, res) => {

  const id = req.params.id;

  const { nome, marca, ano, preco } = req.body;

  const sql = `
    UPDATE carros
    SET nome = ?, marca = ?, ano = ?, preco = ?
    WHERE id = ?
  `;

  connection.query(
    sql,
    [nome, marca, ano, preco, id],
    (erro, resultado) => {

      if (erro) {

        return res.status(500).json({
          erro: 'Erro ao atualizar carro'
        });

      }

      res.json({
        mensagem: 'Carro atualizado com sucesso'
      });

    }
  );

});

9.15 Problema da organização do código

À medida que a aplicação cresce, colocar toda a lógica SQL nas rotas torna o projeto difícil de manter.

Por isso, aplicações reais normalmente utilizam:

  • models;
  • controllers;
  • services;
  • repositories.

Neste capítulo, utilizaremos uma abordagem baseada em classes.

9.16 Organizando o código em classes

Vamos criar uma classe responsável pelas operações da tabela carros.

Arquivo:

models/Carro.js

9.17 Classe Carro

const connection = require('../database/connection');

class Carro {

  listar(callback) {

    const sql = 'SELECT * FROM carros';

    connection.query(sql, callback);

  }

  buscarPorId(id, callback) {

    const sql = 'SELECT * FROM carros WHERE id = ?';

    connection.query(sql, [id], callback);

  }

  inserir(dados, callback) {

    const sql = `
      INSERT INTO carros (nome, marca, ano, preco)
      VALUES (?, ?, ?, ?)
    `;

    connection.query(
      sql,
      [
        dados.nome,
        dados.marca,
        dados.ano,
        dados.preco
      ],
      callback
    );

  }

  atualizar(id, dados, callback) {

    const sql = `
      UPDATE carros
      SET nome = ?, marca = ?, ano = ?, preco = ?
      WHERE id = ?
    `;

    connection.query(
      sql,
      [
        dados.nome,
        dados.marca,
        dados.ano,
        dados.preco,
        id
      ],
      callback
    );

  }

  remover(id, callback) {

    const sql = 'DELETE FROM carros WHERE id = ?';

    connection.query(sql, [id], callback);

  }

}

module.exports = new Carro();

9.18 Utilizando a classe nas rotas

Arquivo:

routes/carros.js
const express = require('express');

const router = express.Router();

const Carro = require('../models/Carro');

router.get('/', (req, res) => {

  Carro.listar((erro, resultados) => {

    if (erro) {

      return res.status(500).json({
        erro: 'Erro ao listar carros'
      });

    }

    res.json(resultados);

  });

});

router.get('/:id', (req, res) => {

  Carro.buscarPorId(req.params.id, (erro, resultados) => {

    if (erro) {

      return res.status(500).json({
        erro: 'Erro ao buscar carro'
      });

    }

    res.json(resultados[0]);

  });

});

router.post('/', (req, res) => {

  Carro.inserir(req.body, (erro, resultado) => {

    if (erro) {

      return res.status(500).json({
        erro: 'Erro ao inserir carro'
      });

    }

    res.status(201).json({
      mensagem: 'Carro inserido'
    });

  });

});

module.exports = router;

9.19 Vantagens da organização em classes

Separar regras em classes oferece vantagens importantes:

  • código mais organizado;
  • reutilização;
  • manutenção simplificada;
  • separação de responsabilidades;
  • melhor escalabilidade.

Segundo a documentação do Express, aplicações maiores normalmente separam rotas, lógica de negócio e acesso ao banco.33
